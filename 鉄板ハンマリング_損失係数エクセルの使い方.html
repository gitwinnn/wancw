第0章　まず言葉から（小学生バージョン）

🔔 「固有振動数こゆうしんどうすう」って何？

お寺てらの鐘かねを叩くと「ゴーン」と鳴ります。同じ鐘は、いつ叩いても同じ高さの音が出ますね。 これは、その鐘が「この速さで揺れるのが一番ラク」という揺れ方をいくつも持っているからです。 その「一番ラクな揺れの速さ」が固有振動数（fn）です。単位は Hz（ヘルツ＝1秒間に何回揺れるか）。

鉄の板も同じで、叩くといくつもの音が同時に鳴っています。だからグラフに山がたくさん並ぶのです。 山1つ＝揺れ方1種類（これをモードゆれかたと呼びます）。

🔕 「損失係数 η（イータ）」って何？

鐘を叩いた後、音はだんだん小さくなって、やがて消えます。この「消えやすさ」を数字にしたものが損失係数 ηです。

  • η が小さい（0.0005 など）＝ なかなか消えない ＝ キーンと長く鳴る（鉄てつの生板はこれ）
  • η が大きい（0.05 など）＝ すぐ消える ＝ ボスッと鳴って終わり（ゴムや制振材せいしんざい）
🍮 たとえ話：プリンをつつくと プルン… ですぐ止まる（ηが大きい）。
下敷したじきをはじくと ビイイイイン と長く続く（ηが小さい）。

📈 「グラフの山（ピーク）」の形と η の関係

覚え方：山が細ければ細いほど、よく響く（ηが小さい）。
山の太さ（半値幅）÷ 山の位置（fn）＝ η　これが一番シンプルな考え方です。

🪟 「窓関数まどかんすう」「指数窓」って何？

FFT分析器ぶんせききは、時間の波を「決まった長さでハサミで切って」から周波数に変換します。 ところが切ったところで波がブツッと途切れると、ニセモノの山ができてしまいます（漏もれ・リーケージ）。

そこで、記録の終わりに向かってだんだん音量を絞るフェードアウトをかけます。これが指数窓（exponential window）です。

🎚️ たとえ話：音楽の最後をフェードアウトさせるのと同じ。ブツ切りの「プツッ」というノイズが消えます。

⚠ ただし副作用があります。フェードアウトは「音が早く消えた」＝「減衰が大きい」と分析器に誤解させます。 つまり η が本当より大きく出るのです。この分は必ず引き算します（→第8章）。

✏️ 「カーブフィット法」って何？

理科りかの実験で、点をたくさん打ってからなめらかな線をスーッと引いたことはありませんか。あれです。

山の形は、理論上こういう形になると分かっています（1自由度じゆうどの式）。 そこで「理論の形を、実測の点にいちばんピッタリ重なるように、fn と η をちょっとずつ動かして合わせる」のがカーブフィットです。

半値幅法よりカーブフィットが優れている理由
・半値幅法は「山のてっぺん」と「−3dBの2点」のたった3点しか使いません。1点でもノイズが乗ると答えがズレます。
・カーブフィットは山の周りの数十点すべてを使うので、ノイズが平均化へいきんかされてずっと安定します。
・さらに「どれくらいピッタリ合ったか」を R²（決定係数）という点数で確認できます（1.0に近いほど良い）。

2-1　指数窓の減衰値はいくつにする？

減衰値を小さくする（例：1%）＝ フェードアウトがきつい ＝ 漏れは減るがηが大きく歪む。
減衰値を大きくする（例：20%）＝ フェードアウトが緩い ＝ 歪みは小さいが漏れが残る。

時定数 τ = − T / ln(r)　　（r = 終端での減衰比、T = 記録時間）
付加される損失係数 Δη = 1 / (π · fn · τ)
終端減衰値 rT=0.64s(20kHz)のτΔη @1kHzT=6.4s(2kHz)のτΔη @1kHz
1 %0.139 s0.002291.390 s0.000229
5 %0.214 s0.001492.136 s0.000149
10 %0.278 s0.001152.779 s0.000115
20 %0.398 s0.000803.977 s0.000080

読み取り方：20kHzレンジ（T=0.64s）だと Δη が 0.001〜0.002 もあります。 鉄の生板の本当のηが 0.0005 なら、測定値の 8割以上が窓のせいということになり、引き算しても誤差だらけです。 → 記録時間 T を長くする（＝レンジを下げる）のが唯一の解決策です。

🏆 究極の正解：窓を「無し」にする
記録時間 T の中で振動が完全にゼロまで収まるなら、窓は不要（［無し］＝方形窓）で、Δη の補正も要りません。
必要な時間の目安：t ≒ 6.9 / (π · η · fn)（振幅が 1/1000 になるまで）。
例：fn=400Hz, η=0.003 → t ≒ 1.83秒 → 2kHzレンジ（T=6.4s）なら余裕でOK。
今回は「指数・指数」指定なのでエクセルは補正機能付きにしてありますが、窓［無し］が使える条件なら、そちらの方が精度は上です。 その場合はエクセルの B15（終端減衰値）に大きな値（例 99.9）を入れれば Δη≒0 になります。

第3章　叩き方・板の吊り方

3-1　吊り方（自由じゆう-自由）

  • ピアノ線 φ0.3〜0.5mm で吊る。ゴムひもはダメ（ゴム自体が減衰を持ち、Q値が2〜3倍悪化する＝ηが大きく出る）。
  • 1/10ルール：吊り具由来の剛体モードが、1次曲げ fn の 1/10 以下になるようにする。効くのは主に線のバウンス（縦揺れ）モード。
  • 吊り点は、板の端から0.224L付近（自由-自由1次の節）を狙うと1次モードを邪魔しません。

3-2　叩く場所とセンサの場所

鉄則
① 叩く点は角（かど）の近く・対称軸から外す。→ 曲げモードもねじりモードも同時に出せる。
② センサは叩く点とは別の場所に置く（同じだと駆動点FRFになり、モード形状が取れない）。
③ 節（せつ＝揺れない線）で叩くと、そのモードは出ません。 山が1つ足りないときは、まずこれを疑う。
④ 対称軸のど真ん中で叩くと、反対称モード（ねじり）が全部消えます。

3-3　叩き方

  • 二度打ち（ダブルヒット）は絶対にNG。 時間波形を見て、山が2つあったらそのデータは捨てる。
  • 強く叩きすぎて波形がクリップ（頭打ち）したデータも捨てる。過負荷LEDが赤く点灯したら即やり直し。
  • 平均なし（1発打ち）なので、1回1回を目で確認してから保存する。これが唯一の品質管理です。
  • コヒーレンスは使えません。 1レコードから計算したコヒーレンスは必ず γ²=1 になり、意味がありません（平均が2回以上必要）。

第4章　データをCSVで出す → エクセルに貼る

  1. SA-01 で測定 → 停止 → グラフを「パワースペクトル」（または伝達関数の振幅）にする。
  2. メニューの［ファイル］系からCSV（テキスト）保存を行う。
    🔴要現物確認 メニュー項目の正確な名前はバージョンによって異なります。実機で「CSV」「テキスト」を含む項目を探してください。
  3. CSVを LibreOffice Calc で開く。先頭にヘッダ行（測定条件）が数行〜数十行入っていることが多いので、数値だけの部分を見つける。
  4. 数値部分の 1列目＝周波数[Hz]、2列目＝レベル をコピー。
  5. エクセルの「データ」シートの A2 セルを選んで貼り付け（形式を選択して貼り付け→値のみ）。
よくある事故
・貼り付けたら数字が文字列になっていた → 右揃えになっていなければ文字列です。［データ］→［テキストから列へ］で数値化。
・小数点が「,」の欧州おうしゅう式になっていた → 読み込み時のロケール設定を確認。
・元のサンプルデータが下に残っている → 貼り付けた行数が 12801 行未満のとき、A列の残りを必ず削除してください（Delete キー）。

第6章　自動ピーク検出のしくみ

「山を見つける」を機械にやらせるには、「山とは何か」を数式で定義しないといけません。このファイルでは4つの条件を全部満たしたときだけ「山」と認めます。

4つの条件

  1. 頂上であること：左 m 点の最大値以上、かつ 右 m 点の最大値より大きい。（設定 B24 = m）
  2. 十分に高いこと：全体の最大振幅から −45 dB 以内。（設定 B25）
    これは「ノイズの床すれすれの小さな山は無視する」というルールです。
  3. 十分に突き出ていること（突出量 / prominence）：左右 M 点の範囲にある「谷（最小値）」のうち浅い方より 6 dB 以上高いこと。（設定 B26, B27）
    🍰 たとえ話：山の高さを「海面からの高さ」ではなく「まわりの谷底からの高さ」で測るということ。 高い台地の上のちょっとした凸凹でこぼこを「山」と呼ばないための工夫です。これが無いと、ノイズのさざ波を数百個も拾ってしまいます。
  4. 指定した周波数帯の中：開始周波数〜終了周波数の間。（設定 B28, B29）
    DC付近のうねりや、吊り具の剛体モード（数Hz〜数十Hz）を除外します。

第7章　カーブフィットのしくみ（数式の導出）

ここは「なぜそうなるか」の説明です。 使うだけなら読み飛ばして構いませんが、 上司に説明するときや、結果を疑ったときに戻ってきてください。

7-1　1自由度系の理論式

1つの山（＝1つのモード）だけを取り出すと、その周りの応答は次の形になります（構造減衰こうぞうげんすいモデル）。

H(f) = A / ( fn² − f² + i·η·fn² )

大きさ（振幅）の2乗をとると：

|H(f)|² = A² / [ (fn² − f²)² + η²·fn⁴ ]

7-2　逆数ぎゃくすうをとると「ただの2次関数」になる（これが仕掛け）

両辺をひっくり返します。

y ≡ 1 / |H(f)|² = [ (fn² − f²)² + η²·fn⁴ ] / A²

ここで v = f² / fp²（fpはピークのおおよその周波数）、vn = fn² / fp² と置き換えると：

y = a₂·v² + a₁·v + a₀　　←　ただの2次関数！

係数と物理量の対応は次のようになります（展開して比べるだけ）：

a₁ = −2·vn·a₂　　→　vn = − a₁ / (2·a₂)　→　fn = fp·√vn

a₀ = vn²·(1 + η²)·a₂　　→　η = √( a₀ / (a₂·vn²) − 1 )
🎯 なぜこれが嬉しいのか
本来のカーブフィットは「非線形最小二乗法さいしょうにじょうほう」で、反復計算はんぷくけいさん（ソルバー）が必要です。
ところが逆数をとると2次関数になるので、エクセルの LINEST（線形回帰）1発で、反復なし・ソルバー不要・一意な解が得られます。
つまり「山の周りの数十点すべてを使った、正真正銘の最小二乗カーブフィット」が、関数1つでできてしまうのです。
※ これは有理分数多項式法（RFP / Rational Fraction Polynomial）の1自由度・分母のみ版に相当します。

7-3　v で規格化きかくかする理由

もし f² のまま計算すると、f=1000Hz で f²=10⁶、f⁴=10¹² となり、桁が違いすぎて計算精度が壊れます（数値的に不安定ふあんてい）。
v = f²/fp² と割ると v ≒ 1 付近の小さな数になり、精度が保たれます。エクセルの数式で /$C5^2 と割っているのがこれです。

7-4　2回フィットする理由（帯域の自動調整）

  1. 1回目：とりあえず ±25点 の固定幅でフィット → ざっくり η を推定。
  2. 2回目：得られた η から 帯域幅 = 1.5 × η × fn を計算し、その幅（点数に換算）で再フィット。

これで、細い山には狭い帯域、太い山には広い帯域が自動的に割り当てられます。 帯域が広すぎると隣の山が混ざり、狭すぎると点数が足りません。この自動調整が精度の要です。

7-5　R²（決定係数）の見方

R²意味対応
0.99 以上非常に良いそのまま採用
0.90〜0.99おおむね良い採用可。念のためグラフ確認
0.90 未満悪い双子モード・ノイズ・分解能不足を疑う

第8章　指数窓の補正（なぜ引き算するのか）

8-1　しくみ

指数窓は時間波形に w(t) = exp(−t/τ) を掛けます。 一方、揺れそのものも exp(−ζ·ωn·t) で減っています。掛け算すると：

exp(−ζ·ωn·t) × exp(−t/τ) = exp( −(ζ·ωn + 1/τ)·t )

つまり「実際より 1/τ だけ速く減衰した波」に見えます。減衰比に直すと Δζ = 1/(ωn·τ)、 損失係数は η = 2ζ なので：

Δη = 2/(ωn·τ) = 2/(2π·fn·τ) = 1/(π·fn·τ)

η真 = η実測 − Δη

8-2　補正が効かなくなる限界

Δη が η実測 の半分を超えたら、その値は信用してはいけません。
引き算した後に残るのが「小さい数どうしの差」になり、桁落けたおちで誤差が暴れます。
エクセルの判定（AF列）では η実測 > Δη × 1.05 を条件に入れていますが、 実用上は Δη ≦ η実測 × 0.3 を目標にしてください。
→ 満たせないときは 記録時間 T を長くする（レンジを下げる）か 窓を［無し］にする。

第9章　結果の読み方と「要確認」の対処

  • R²（2回目）≧ 0.9
  • 補正後の η > 0
